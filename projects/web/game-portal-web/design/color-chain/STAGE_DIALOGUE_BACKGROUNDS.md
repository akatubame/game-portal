# ステージ入場・会話シーン用背景 v1

制作日：2026-10-01。生成方法：内蔵画像生成ツール（imagegenスキル）。世界観の参照は `public/backgrounds/chroma-world-map-v1.webp`。

## 用途と配置

マップのステージ選択演出後、パズルに進む前にクロマと敵が対峙し、会話するための背景。6舞台を個別に制作。キャラクター、会話の文字、ボタンは後から重ねる。

- 固定1280×720の画面に16:9で表示する。ゲーム用WebPは1600×900、生成PNG原画も保持。
- クロマは左側、足元の基準を横23%・縦76%（1280×720では約294,547）にする。
- 敵は右側、足元の基準を横77%・縦76%（約986,547）にする。浮遊する敵もこの位置を基準に高さを調整する。
- キャラクターは目安として画面高の35〜40%で表示し、クロマは右向き、敵は左向きの素材を使用する。衣装の左右が固定されたキャラは単純反転に注意する。
- 下部20%（縦80%以降）に会話ウィンドウを配置。足元と会話欄の間には余白を残す。
- 会話画面・台詞・ステージ遷移の組み込みは次の実装段階で行う。今回は背景素材を制作・保存する段階。

共通構図：固定画面に2.5頭身のキャラを後から合成する。クロマの足元は横23%・縦76%、敵の足元は横77%・縦76%。その2地点と間の横10〜90%・縦53〜80%は連続した広く平らな地面・床の広場にする。キャラクターの全身が来る左右の横12〜34%／横66〜88%、縦32〜77%に、大きな近景の障害物、柱、草、岩、強い光、細かい装飾を置かない。キャラは床に立ち、互いの顔を向けられる、同じ床面高さ。左右対称の不自然なステージ円盤・足場・ペデスタルは不要。背景の景観は奥の上半分と左右端に置く。カメラは正面寄り、床の遠近は緩やかに、中央へ強烈に収束する道や極端な俯瞰は避ける。会話欄を後から重ねる下20%は控えめな床や地面の色と質感で描き切る。上8%も重要な物を避ける。画面全体を美しく描き、透明部分や白い空白は作らない。キャラの輪郭が読みやすい中程度の明度と穏やかなコントラスト。魔法の鎖は小さな金色の輪や短い連結として遠景の端に控えめに散らす。ホラーや戦争の景色にはせず、可愛い魔物と冒険する明るい魔法世界。1枚の景色のみ、分割画面やコラージュは禁止。必ず横長16:9。
