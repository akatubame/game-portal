# 魔法の森・入場会話シーン v1

制作日：2026-10-01。対象：回転式Web版とAndroid試遊版0.3.0。

## 画面の流れ

マップで魔法の森へ到着 → 同じ地点を再タップ（または未プレイ時の「モコスライムと遊ぶ」）→ 既存の選択ポーズと09_glock_run.mp3 → 会話画面 → クロマの歩行入場 → 2往復・4台詞 → 「パズルへ進む」。

- クロマは左画面外から1.8秒で左側へ右向きに歩き、停止時に正面寄りの右向き立ち絵へ切り替える。顔だけでなく胸・腰・両足先も右へ向ける。モコは右側で左向きに対峙する。クロマの表示高300px、モコ150px（1/2）で足元を揃える。
- 背景はstage-dialogue/magic-forest-v1.webp。固定1280×720を全体縮尺表示し、スクロールは使わない。
- 台詞は28msごとに1文字ずつ表示。途中でタップすると全文表示、全文表示後にタップすると次の台詞へ進む。台詞が揃った後は更新タイマーを停止。
- Enter・Spaceでも進行可能。Escapeはマップへ戻る。明示的なスキップボタンあり。
- 日本語と英語を同時制作。言語切替でも会話の進行位置を保持する。
- 会話中はパズルの時計・妨害ゲージを停止し、既存の盤面を保持。会話を終えると新規開始または再開。
- 未プレイ時のステージ選択は会話を挟む。プレイ途中の「パズルを再開」ボタンは直接再開できる。
- 演出OFF／動き低減設定では即時登場・台詞全文表示。アプリの中断・タブ非表示時は歩行と文字表示を一時停止。
- マップへ戻る・スキップ・画面を閉じる際にイベント・タイマーを解除。素材が読み込めない場合は既存キャラと背景色へフォールバック。
- 他の5舞台の会話は今後追加する。

## 素材と実装

- モコの会話用左向き素材を内蔵画像生成ツール（imagegenスキル）で新規制作。
- 原画：reference/moko-dialogue-left-v1-source.png。参照：public/characters/moko/moko-idle.png。
- 実装用：public/characters/moko/moko-dialogue-left-v1.webp。透明余白のトリミングと縮小・WebP変換のみ実施（512×450）。
- クロマは歩行中に既存のchroma-map-walk-v1.webpの右向き4コマを使用。停止時はchroma-dialogue-idle-right-v2.webpを使用。服の左右反転は行わない。
- 停止立ち絵は内蔵画像生成ツールで既存デザインを参照して制作。原画：reference/chroma-dialogue-idle-right-v2-source.png。実装用：public/characters/chroma/chroma-dialogue-idle-right-v2.webp。透明余白のトリミング・高さ600pxへの縮小・WebP変換のみ実施。生成プロンプト：reference/chroma-dialogue-idle-right-v2-prompt.md。他の画面の素材は変更しない。
- 会話本体：src/games/colorChain/ColorChainStageDialogue.tsx。
- 見た目：src/games/colorChain/stageDialogue.css。
- Android素材同梱処理へ魔法の森背景を追加。キャラは既存ディレクトリ同梱処理で含める。
