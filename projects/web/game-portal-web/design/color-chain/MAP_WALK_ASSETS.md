# マップ用クロマの歩行素材（2026-10-01）

## 仕様

- 内蔵画像生成ツールとimagegenスキルで、既存デフォルメ設定画を参照して新規制作。
- 原画：`reference/chroma-map-walk-v1-source.png`（透過PNG）。
- 実装素材：`public/characters/chroma/chroma-map-walk-v1.webp`（透過1024×1024）。
- 4列×4行。上から手前向き・奥向き・左向き・右向き。各行4コマ。
- `scripts/prepare-chroma-map-walk.mjs`で均等切り出し・足底の高さ調整・WebP圧縮のみ実施。衣装の左右反転は行わない。
- 道の各区間に合わせて向きを変更。左右判定には地図の16:9比率を反映する。
- 移動中は0.56秒の4コマ歩行。到着後は正面を向いて静止する。
- 現在地を再タップすると、既存のchroma-chain.webpで笑顔で腕と杖を上げ、魔法の輪・きらめき・短い光を表示。約1.2秒後に正面静止に戻る。
- ステージ選択SEはユーザー提供のE:/SD/Codex/09_glock_run.mp3をpublic/audio/color-chain/stage-select-glock.mp3に同梱し、共通音声処理から再生。サウンドOFFを尊重し、演出OFF／動き低減時は笑顔の静止ポーズのみ表示する。
- 演出中の連打・別地点への移動は抑制。戻る操作は可能で、終了時にタイマーを解除する。魔法の森では完了後に入場会話へ進み、会話を終えるとパズルを開始・再開する。詳細はSTAGE_DIALOGUE_IMPLEMENTATION.md。
- 演出OFF／動き低減設定は即時移動。素材読込失敗時は従来の立ち絵にフォールバック。
- Web・Android共通。Android同梱処理はcharacters/chromaディレクトリをまとめて取り込む。
- QA：全36経路・4方向・曲がり角の単体テスト、PC／スマホ相当のブラウザで往復・4コマ・停止・読込失敗時を確認。

## 生成プロンプト

```text
添付画像はクロマの外見の参照設定画です。このキャラクターの地図移動用、背景が完全透明な実装用歩行スプライトシートを制作してください。設定画ではなく、ゲームで切り出して使う素材です。
構成：正方形の画像に厳密な4列×4行の均等グリッド。16体のみ。文字・罫線・パネル・背景・地面・影・エフェクトなし。各セルの中央に同じ大きさの全身キャラ、足底の高さを統一、帽子と杖を含め全身がセル内に収まり、セル端から10％の透明余白。透明背景を必ず維持。
行順：1行目は正面を向いて手前に歩く。2行目は背面を向いて奥に歩く（顔は見えない）。3行目は左向きの完全横向きで左へ歩く。4行目は右向きの完全横向きで右へ歩く。
各行4コマの順番：左足を前に踏み出す、足を寄せた中間姿勢、右足を前に踏み出す、足を寄せたもう一つの中間姿勢。左右の足の位置変化をはっきり描き、帽子・頭部・衣装の大きさ位置はコマ間で極力一定。杖を持ち、空いた手は小さく振る。大股の走りではなく可愛らしい歩行。
既存デザインを厳密に維持：2.5頭身の小さな魔女、紺紫の髪、紫の瞳、大きな紺色の魔女帽子、金の鎖飾りと菱形宝石、マゼンタとシアンの差し色、短い紺のケープとスカート、金縁、宝石付きの金の短い杖、ブーツ。特に背面は参照設定画のケープと帽子を尊重。人物を左右反転して複製するのでなく各視点で描き下ろし、装備は同じ手に保持する。細かい装飾は地図用に少し簡潔に。輪郭が明瞭な、明るく高品質のデフォルメアニメ彩色。全16セル、各セル1体のみ。
```
