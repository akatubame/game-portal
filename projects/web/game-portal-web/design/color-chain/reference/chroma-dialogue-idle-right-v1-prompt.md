# クロマ・会話停止立ち絵（正面寄り右向き）

2026-10-01。内蔵画像生成ツールを使用。参照は既存の歩行シートと通常立ち絵。

## 生成プロンプト

用途：既存キャラクターの向きだけを調整する背景透過ゲーム用立ち絵。入力画像1はクロマの歩行スプライト（外見・頭身・描画スタイル基準）、画像2は衣装詳細の参照。歩行シートを作るのではなく、クロマ1人の全身の静止立ち絵を1枚描いてください。
変更点：正面をベースとして頭と体を画面右へわずか20〜25度向ける。真横ではなく正面に近い浅い三分の四正面。両目がよく見えて、右にいる話し相手へ視線を向ける。笑顔は穏やか、杖は下向きに持ち、両足で自然に立ち止まる。
不変事項：歩行スプライトと同じ約2.5頭身のデフォルメ、紫の瞳、濃紫のボブ、ピンク・青の毛先、紺紫の大きな魔女帽子、金の鎖飾り、虹色の菱形宝石、金縁の紺衣装、ピンク・青の差し色と短いケープ、ブーツ、鎖付きの宝石杖。服と杖を左右反転しない。既存同様の細い明瞭な輪郭・アニメ彩色・柔らかな立体感。頭身を高くしない。帽子から靴まで欠けない。
構図：正方形キャンバス、全身を中央、余白約10%、背景は完全透明、床も影も文字も枠もエフェクトも他キャラもなし。会話シーンで歩行から停止時に切り替えるための、正面寄りの右向き立ち絵だけ。
