# 特殊魔法エフェクト素材仕様

## 共通仕様

- 用途: 盤面回転式「クロマのマジカルチェイン」の2D魔法エフェクト
- 形式: 左から右へ進む4コマ横並びスプライト
- 寸法: 2172×724px（1コマ543×724px）
- デザイン基準: シアン～青の魔力光、白い発光芯、金縁の太い鎖、宝石状のハイライト
- 輪郭: ゲーム盤上で縮小しても、鎖の輪と魔法の進行方向を判別できる太さ
- 禁止要素: キャラクター、盤面、UI、文字、数字、透かし、コマ境界線
- 生成背景: 単色 `#00FF00`
- 実装素材: クロマキー除去、ソフトマット、デスピル処理済みの透過PNG

## 魔法別の4コマ構成

### チェインピラー

1. 足元に鎖の魔法陣と火花が出現
2. 複数の太い鎖が上昇開始
3. 鎖と青い魔力炎が垂直に激しく噴き上がる
4. 鎖が破片と星へ分解して上方へ消散

### チェインボム

1. 4本の鎖が魔力核へ巻き付く
2. 球状の封印となり中心が白熱
3. 円形の青金色爆発とともに鎖が放射状に飛散
4. 鎖片、星、残光が外側へ消散

### トリニティピラー

1. 横一列に3つの鎖魔法陣が点火
2. 3本の鎖柱が上昇開始
3. 金色の放電で連結された3本の巨大な鎖柱が噴出
4. 3本の柱が鎖片と星へ分解して消散

### トリニティウェーブ

1. 左端に縦3段の鎖魔法陣が点火
2. 3本の鎖が平行に右へ走り始める
3. 金色の放電でつながった3本の鎖が画面幅を横断
4. 鎖片と星が右方向へ流れながら消散

### グランドチェインボム

1. 二重の鎖輪が巨大な魔法陣を包み込む
2. 鎖輪が球状封印となり金色の十字が固定
3. 巨大な円形衝撃波と鎖が広範囲へ爆発
4. 大量の鎖片、星、円形残光が外側へ消散

### プリズムブレイク

専用の派手なスプライト画像は使用しない。対象色のブロックと発動した
プリズムブレイク本体が、その場で2回転しながら縮小・透明化して消える。
プリズムノヴァとの格の違いを明確にし、盤面上で対象色を追いやすくする。

生成済みの4コマ案は未使用資料として次の場所に保管する。

`design/color-chain/effects/archive/prism-break-sprite-unused.png`

### プリズムノヴァ

1. 二重鎖輪と8つの宝石星が巨大プリズムを包囲
2. 天体魔法陣として固定され、中心へ全色の光が収束
3. 虹色の巨大な円形ノヴァ、鎖、宝石片が盤面全体へ炸裂
4. 鎖輪、結晶片、多色の星、円形残光が荘厳に消散

## 保存先

ゲーム実装用の透過素材:

`public/effects/color-chain/<spell-name>-sprite.png`

プリズムブレイクのみ画像を使用せず、CSSアニメーションで描画する。

## 生成方法

既存のチェインウェーブ原画をスタイル参照として、画像生成機能で魔法ごとに個別生成した。透過版はクロマキー除去ツールを使用し、次の条件で変換した。

- 背景色: 四隅を基準に自動抽出
- 透明しきい値: 12
- 不透明しきい値: 220
- ソフトマット: 有効
- グリーンデスピル: 有効
