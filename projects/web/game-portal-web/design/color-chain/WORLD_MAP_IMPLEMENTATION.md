# ワールドマップ v1（2026-10-01）

## 実装範囲
- 対象：回転式カラーチェイン／クロマのマジカルチェイン、Web・Android共通。
- ゲーム上部の「マップモード」で、固定1280×720の横長画面内を地図に切り替える。
- 6地点をタップ、または前後ボタン・左右キーで、ミニクロマが道に沿って移動する。到着後は正面向きに静止する。
- 現在地を再タップすると、笑顔で腕と杖を上げる出発演出とSEを再生。魔法の森は約1.2秒後に入場会話へ進む。他の舞台は静止に戻る。
- 現在地は端末内に保存。途中で閉じた場合は最後に到着した地点を保持する。
- マップ表示中は盤面とプレイ記録を保持し、残り時間・妨害ゲージを停止する。
- 連鎖解決中は切り替えを無効にし、演出終了後に開く。
- 魔法の森から既存のモコスライム戦を開始・再開できる。他の5地域は散策のみ。各敵のバトル・会話・ステージ解放は今後の実装。
- 地域名・説明・操作案内は日英対応。文字は背景画像に描き込まずUIに表示する。
- 演出OFF／端末の視差効果低減時は移動アニメーションを省略する。

## 素材
- 生成方法：内蔵画像生成ツール（imagegenスキル）
- 生成原画：reference/chroma-world-map-v1-source.png
- ゲーム用：public/backgrounds/chroma-world-map-v1.webp
- 移動キャラ：public/characters/chroma/chroma-map-walk-v1.webpの上下左右4方向×4コマ歩行。曲がり角で向きを変更し、到着時は静止。詳細はMAP_WALK_ASSETS.md。
- 地域・座標・経路：src/games/colorChain/worldMap.ts
- Android：同梱素材ビルドに追加。0.2.0で搭載。
