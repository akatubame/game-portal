# Game Shelf ゲーム品質改善・第15段階

実施日: 2026-10-06

## 途中保存・再開を4ゲームへ追加

Water Sort Puzzle、マインスイーパー、迷路脱出、Hit & Blowにブラウザ内の進行中データ保存を追加した。再読み込み後は同じ局面から続けられる。計時は閉じていた時間を加算せず、再開後から進む。新規開始で古い局面を破棄し、クリア・失敗時は途中記録だけを消す。ベスト記録とランキングのキー・計算方法は変更しない。

| ゲーム | 保存内容 | 主な検証 |
| --- | --- | --- |
| Water Sort Puzzle | レベル、色水、手数、Undo履歴 | 色の総数、容量、合法な注ぎの連続、未完成状態 |
| マインスイーパー | 難易度、地雷・数字・開封・旗、旗モード、状態、経過秒 | 盤面寸法、地雷数、隣接地雷数、初手前は未配置、未決着 |
| 迷路脱出 | 難易度、壁配置、プレイヤー位置、手数、経過秒 | 外壁、隣接壁の対称性、全マスへの到達可能性、未ゴール |
| Hit & Blow | 難易度、答え、入力中の数字、判定履歴、経過秒 | 4桁の重複なし、判定結果の再計算、制限回数内、未正解 |

各保存キーは `game-shelf-progress-*-v1`。壊れた保存値は読み込み時に削除せず、ゲームの初期状態を表示する。途中再開は現在のブラウザ内のみであり、別端末間の同期には対応しない。Hit & Blowの答えはローカル保存値から閲覧可能なため、対戦や賞金を伴う用途には使わない。

## 検証

`npm run test:portal-phase15` を追加。4ゲームについて、実際の操作後の再読み込み、途中状態の復元、新規開始、クリア後の途中記録削除、不正な保存値の拒否を確認する。Water SortのUndo、マインスイーパーの初手安全性、迷路の壁整合性も対象。320px・390px幅の横はみ出しを検査する。一括回帰 `npm run test:portal-regression` に組み込んだ。

検証結果: 第15段階の個別ブラウザテスト、全19群の一括回帰テスト、将棋・麻雀の内包とPWA生成を含む公開用ビルドが成功。`git diff --check` もエラーなし。第13～15段階で途中再開に対応したゲームは計13作。

実機スマートフォンの操作、別端末間の同期、残りのゲームの途中保存は未対応。この作業からのcommit・push・deployは未実施。
