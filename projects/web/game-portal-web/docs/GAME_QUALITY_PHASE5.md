# Game Shelf ゲーム品質改善・第5段階

実施日: 2026-10-05

## 今回の対応（迷路脱出）

- サイズ別に最短手数と最短時間を独立して更新・表示する。
- 従来の手数優先ベストは保存キーを維持。最短時間は新しいキーで記録する。以前の最速結果は復元できないため、過去の手数ベストに付随する時間を最速記録として移行しない。画面にも新記録の対象期間を案内する。
- 新しい時間記録にも既存の保存データ検証を適用。
- クリア結果を数値・サイズ・記録更新フラグのスナップショットにして保持し、クリア文とランキング登録値をそこから生成する。ベスト削除や言語切替では今回の結果を変更しない。新しいゲーム・サイズ変更で結果をリセットする。
- 説明、進行・クリアメッセージ、サイズ選択、ボタン、読み上げラベルを直接日英表示へ移行。旧DOM翻訳の対象から外す。
- 入力欄・選択欄の矢印キー操作をゲームが横取りしないようにする。
- ランキングは従来どおり時間順位。手数ランキングの追加や、同一問題間での比較機能は今回の対象外。迷路が毎回ランダムであることを表示する。

## 検証

- `npm run test:portal-phase5`: 9×9の迷路を表示された壁から探索して自動完走。時間だけ／手数だけの独立更新、旧手数記録保持、日英表示、削除キャンセル・確定、終了後の計時停止、削除後のランキング登録、新規開始時の結果解除を確認。
- 第3段階の8ゲーム計時・終了記録テストと、第4段階の補助別記録・28ゲームのリセット確認テスト成功。
- 保存処理・数独のコアテスト成功。本番ビルドは内包将棋・麻雀も含めて検証。
- 隔離Edge・390px幅で対象ローカルorigin以外の通信を遮断。実スマートフォンや本番サイトでの検証は含まない。
