# Game Shelf ゲーム品質改善・第18段階

実施日: 2026-10-06

## 継続型ゲーム4作の途中再開

リバーシ、スネーク、ブロック崩し、ポンの進行中データをブラウザ内に保存する。リバーシは盤面・手番・難易度・直前の手を復元し、COM手番なら処理を再開する。スネーク、ブロック崩し、ポンは予期しない操作ミスを防ぐため、再読み込み後は必ず一時停止で復元し、「再開」を押すまで動かさない。

スネークは各移動後に保存する。ブロック崩しとポンは描画のたびにストレージへ書かず、プレイ中は500ms間隔とページ離脱時、一時停止時に保存する。いずれも新規開始で以前の途中経過を捨て、敗北・勝利・クリアで途中経過だけを消す。既存のベスト記録とランキングは維持する。

読み込み時には形式バージョン、盤面サイズ、座標と速度の有限値、得点・残機の範囲などを確認する。スネークは体の連結・重複・リンゴの位置、ブロック崩しは40個のブロック配置、リバーシは初期配置と未決着状態も確認する。壊れたデータは読み込まず、元データそのものは読み込み時に削除しない。

## 検証

`npm run test:portal-phase18` を追加。4作で英語UIの再読み込み、復元後の継続、勝敗時の保存削除、新規開始、不正保存値の拒否を自動操作で確認する。320px・390px幅の横はみ出しも確認する。`npm run test:portal-regression` に統合した。

検証結果: 第18段階の個別テスト、全22群の一括回帰テスト、将棋・麻雀の内包とPWA生成を含む公開用ビルドが成功。`git diff --check` もエラーなし。

第13～18段階で途中再開に対応したゲームは計28作。短時間の計測・反射ゲーム、公開対象外のハングマン、別途開発中のカラーチェインは今回の途中再開対象外。別端末間同期は行わない。この作業からのcommit・push・deployは未実施。
