# Game Shelf ゲーム品質改善・第8段階

実施日: 2026-10-06

## 対応内容

### ポーカー

- 進行・交換枚数・役名・最高役・説明・操作ボタンを直接日英表示へ移行。
- 交換後の枚数を状態として保持し、言語を切り替えても結果説明を再生成できるようにする。
- 日本語の役名で保存されている既存ベスト記録を維持し、英語画面では対応する英語名を表示。
- カードに選択状態の読み上げ属性を追加。交換できない状態ではカードを無効化。
- ゲーム領域を従来のDOM翻訳対象から除外。

### ヨットダイス

- 得点記録メッセージの役名だけ日本語が残る問題を修正。
- 日本語メッセージを正規表現で英訳する処理を廃止し、最後に記録した役ID・点数とゲーム状態から日英の文を生成。
- 新規開始ボタンを直接日英表示化し、ゲーム領域を従来のDOM翻訳対象から除外。
- ルール、得点計算、保存キーは変更しない。

## 検証

追加コマンド: `npm run test:portal-phase8`

- ポーカー: 交換2枚→1枚への選択変更、選択解除、1枚交換、交換なし、日英往復、旧最高役の英訳、ストレートフラッシュ800点のランキング保存。
- ヨットダイス: ホールド、3回のロール上限、全13ラウンド完走、各役記録後の日英往復、70点の終了・保存、ベスト削除後の今回結果保持、新規開始で結果解除。
- 型チェック成功。隔離Edge・390px幅で外部通信を遮断して実行。実スマートフォンの検証ではない。
- 最終英文調整後の再テスト成功。内包将棋・麻雀を含む本番用ビルド成功。
