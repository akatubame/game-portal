# Game Shelf ゲーム品質改善・第9段階

実施日: 2026-10-06

## 対応内容

三目ならべの直接日英表示への移行。

- 日本語メッセージを保存する状態を削除。盤面・手番・勝敗から現在言語の案内を生成。
- 待機、プレイヤー手番、COM思考中、勝ち、負け、引き分けを日英対応。
- 説明、難易度の名前と解説、操作ボタン、戦績表示、ヒント、ランキング補足を直接日英表示。
- マスの読み上げラベルを日英対応し、使用済みマスにも位置番号を付加。
- 終局後の状態欄を「待機中」から「対局終了」に修正。
- 旧DOM翻訳の対象から除外。対局ロジック・難易度・保存キーは変更しない。

## 検証

`npm run test:portal-phase9` を追加。

- Easyで勝利、Hardで敗北と引き分けになるよう盤面を操作して完走。
- 各手番、COM思考中、終了後に日英往復切替。英語画面に日本語が残らないことを確認。
- 各対局の戦績加算が1回のみであること、勝利時ランキングが1連勝で保存されること、負け・引き分けでは登録欄が出ないことを確認。
- 新規開始で盤面と終了結果を解除することを確認。
- 第6段階の5ゲームの終了記録回帰テスト、内包将棋・麻雀を含む本番用ビルドに成功。差分の空白エラーなし。
- 隔離Edge・390px幅。外部通信を遮断し、実ユーザーの記録は使わない。実スマートフォンの検証ではない。
