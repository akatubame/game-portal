## 共通化

- `useLocalizedMessage` でイベント発生時の日英文と数値を同時に保持する。表示言語が変わってもゲームの進行状態、タイマー、記録を変更しない。
- 更新関数は安定した参照にして、COM待機タイマーやキーボード処理が言語切替だけで再開されないようにする。
- 対象8ゲームの領域に `data-native-i18n` を付け、旧DOM翻訳から除外する。
- これは表示メッセージの共通化であり、全ゲームの保存結果を共通データ型へ移したものではない。
- 保存キー、既存ベスト・ランキングは維持する。内包将棋・麻雀、別開発カラーチェイン、非掲載ハングマンのコードは変更しない。

## 新規検証

`npm run test:portal-phase10`

- 時間制4ゲーム: 連続正解／ヒット、ミス、コンボ、時間切れ、日英往復、画面・ベスト・ランキングのスコア一致、ベスト削除後の今回結果保持、再開。

- Word Guess: 短い入力・候補外の単語、途中判定、勝利・6回失敗、候補案内、入力欄へのキー干渉防止、2回での正解記録保存。
- コネクトフォーとNim: 勝利・敗北、COM思考中と終了後の日英往復、勝利記録保存。
- 英語のゲーム領域の本文と読み上げ属性に日本語が残らないこと、言語往復でメッセージとスコアが変わらないことを確認。
- 隔離Microsoft Edge・390px幅、仮想時計を使用。対象ローカルorigin以外の通信を遮断し、実ユーザーの保存領域は使わない。
- 実スマートフォン、全難易度の全パターン、本番サイトは未検証。コネクトフォーの引き分けは今回の新規完走テストに含まない。
