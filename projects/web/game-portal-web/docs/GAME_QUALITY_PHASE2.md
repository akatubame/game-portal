# Game Shelf ゲーム品質改善・第2段階

更新日: 2026-10-04

## 今回の修正

- 三目ならべ・リバーシ・コネクトフォー・Nim: 難易度変更時に新しい対局を開始し、前の勝利を新しい難易度へ登録できないようにする。同じ難易度の再選択ではリセットしない。連勝ランキングを持つゲームは難易度変更で現在の連勝数を0に戻す（通算勝敗・過去ランキングは保持）。Nimは山構成変更時も連勝をリセットする。
- ポン: 難易度変更時には前回結果と一時停止中の対局を終了し、開始待ちに戻す。旧対局を違う難易度で継続して記録しない。
- ランキング共通: 登録時は対象ゲームの保存済み一覧を読み直す。不正な数値の登録を拒否。登録済み判定をゲームIDと数値に基づかせ、言語切替だけで同じ記録を再登録できないようにする。
- 2048: 盤面更新関数内のスコア加算・ランダム生成・保存などの副作用を外へ移動。StrictModeの状態更新再評価で二重加算しない。入力欄・選択欄・ボタン・編集可能要素・IME変換中はゲーム用キーを処理しない。
- Simon Says: 完走・失敗時は確定スコアを画面にも表示。12ラウンド完走は表示・保存・ランキングのすべて120点とする。
- 反射神経テスト: 記録リセットで合図待ちタイマーと計測開始時刻も解除。
- エイム練習・タイピング・計算ゲーム・カラー判定・もぐらたたき: 共通の締切式タイマーへ移行。非表示タブなどでタイマー通知が遅れても、復帰時は実経過時間を反映。締切後の操作で加点しない。プレイ中の再開始も締切を更新する。
- イラストロジック: Enter/Spaceによる塗り・解除・×入力に対応。ポインターのドラッグと二重処理しない。フォーカスと塗り状態を支援技術に伝える。
- 15パズル・ライツアウト・ハノイ: クリア時に1秒未満を1秒として保存する既存仕様に合わせ、表示時間も同じ値へ確定する。

## 検証

- `npm run test:portal-phase2`: 新規のブラウザ回帰テスト。2048の2+2=4点、入力欄のWASD、三目ならべの勝利→登録→言語変更→難易度変更、反射神経の待機中リセット、イラストロジックのEnter/Space、Simon Says12ラウンド完走、時間制5ゲームの再開始・長時間経過を確認。
- `npm run test:portal-core`: 数独9問と保存の正常・異常系を確認。
- `npm run test:portal-browser`: 第1段階の操作回帰と、公開内蔵34ゲームの通常・保存拒否・不正保存データ条件での起動確認。
- 既存のカラーチェイン3種のロジックテスト。
- `npm run build`: 内包ゲーム・PWA・静的ページを含む全体ビルド。

ブラウザテストは第1段階と同じローカル4180番サーバー、既存Playwright、Microsoft Edge、隔離プロファイルを使用。外部通信を遮断する。実スマートフォンでの確認・全ゲーム全難易度の完走・本番公開確認は含まない。

## 残る改善作業

2026-10-05追記: カウントアップ8ゲームと共通ランキング・神経衰弱の直接翻訳への対応は GAME_QUALITY_PHASE3.md を参照。

今回の修正は監査で確認した優先度中の不具合が中心であり、サイト全体の改善がすべて完了したことを意味しない。

- DOMを後から書き換える翻訳の全廃と、各ゲームでの直接的な日英表示への移行。
- すべてのゲームについて終了結果を共通の結果データとして扱う大規模な整理。今回は確認済みの不一致を修正した。
- カウントアップ式ゲームを含む計時方式のさらなる統一（今回の締切式移行は制限時間のある5ゲーム）。
- ヒント利用時の記録分離、途中保存、記録削除時の確認、迷路の最短手数と最短時間の独立記録などの仕様改善。
- 実機スマートフォンでの追加QAと、全ゲームの完走カバレッジ拡大。

既存の未コミット作業は保持。将棋・麻雀と別開発中のカラーチェインのゲームロジックは変更していない。commit・push・deployは実行しない。
