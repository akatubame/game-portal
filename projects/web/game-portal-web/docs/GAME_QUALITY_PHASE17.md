# Game Shelf ゲーム品質改善・第17段階

実施日: 2026-10-06

## 途中保存・再開を6ゲームへ追加

ブラックジャック、Nim、三目並べ、コネクトフォー、1to50、ソリティアの進行中データをブラウザ内に保存する。ページを再読み込みしても続きから遊べる。新規開始では古い局面を破棄し、勝敗・クリア後は途中データだけを消す。ベスト記録とランキングの保存形式は変更しない。

| ゲーム | 保存内容 | 読み込み時の主な検証 |
| --- | --- | --- |
| ブラックジャック | 山札、双方の手札、Hitの有無 | 52枚の重複・欠損、プレイヤー未バースト、未決着 |
| Nim | 山の構成、難易度、残り石、手番 | 石の上限、残り石の存在、COM手番の再開 |
| 三目並べ | 9マス、難易度、手番 | X・Oの手数、未決着 |
| コネクトフォー | 6×7盤面、難易度、手番 | 石の数・落下位置、未決着 |
| 1to50 | 数字盤面、次の数字、ミス数、経過時間 | 1～50の進行に沿った数字の入れ替わり、重複なし |
| ソリティア | 山札、捨て札、4組札、7場札、手数、経過時間 | 52枚の重複・欠損、表裏、組札の順序、未完成 |

COM手番中のNim・三目並べ・コネクトフォーは再読み込み後にCOM処理を再開する。1to50は閉じていた時間を計上せず、ヒント待ち時間は再開時にリセットする。ソリティアも閉じていた間はタイマーを停止する。保存キーは `game-shelf-progress-*-v1`。破損データは復元せず、読み込み時には削除しない。

## 検証

`npm run test:portal-phase17` を追加。6ゲームで再読み込み、新規開始、決着後の途中データ削除、不正な保存値の拒否を確認する。1to50は50まで、ソリティアは最後の1枚を組札へ置いてクリアする。320px・390px幅の横はみ出しも検査する。全体の `npm run test:portal-regression` に組み込んだ。

検証結果: 第17段階の個別テスト、全21群の一括回帰テスト、将棋・麻雀の内包とPWA生成を含む公開用ビルドが成功。`git diff --check` もエラーなし。第13～17段階で途中再開に対応したゲームは計24作。既存の数独記録テストに保存完了待ちを追加し、テストのタイミング依存を減らした。

実機スマートフォン、別端末間の同期、残りのゲームの途中保存は未対応。この作業からのcommit・push・deployは未実施。
