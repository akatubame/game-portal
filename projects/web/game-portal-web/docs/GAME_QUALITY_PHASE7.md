# Game Shelf ゲーム品質改善・第7段階

実施日: 2026-10-05

## 対応範囲

ブラックジャックと反射神経テストを、旧DOM翻訳に依存しない直接日英表示へ移行した。

### ブラックジャック

- 日本語の進行メッセージを状態として保存する方式をやめ、ゲーム状態と手札から現在言語のメッセージを生成。
- 通常勝利、ブラックジャック、敗北、バースト、引き分けに対応。
- ヒット後の案内も日英対応。終了後に言語を切り替えても結果・点数は維持する。
- ゲーム領域を旧DOM翻訳の対象外に指定。ルール・記録保存形式は変更しない。

### 反射神経テスト

- 待機・合図・フライング・測定完了メッセージ、説明、操作ボタン、読み上げラベル、履歴欄を直接日英表示。
- 測定完了後の状態欄が「待機前」になっていた点を修正。
- 平均0msを未記録扱いにせず、数値として表示する。
- 記録リセットの既存動作（履歴と直前結果を消して待機前へ戻る）は保持する。

## 検証

- `npm run test:portal-phase7` を追加。ブラックジャックの配札をテスト用乱数で再現し、待機・進行・5種類の終了を日英往復で確認。
- 反射神経テストは仮想時計で待機、フライング、合図、250msの測定、リセットを確認。
- 英語表示に日本語が残らないことと、ブラウザの未捕捉例外がないことを検証。
- 第6段階の5ゲームの終了記録・リセット・ランキング保存テストも成功。
- 内包将棋・麻雀を含む本番用ビルド成功。差分の空白エラーなし。
- 隔離Edge・390px幅、外部通信遮断で検証。実スマートフォンでの確認ではない。
