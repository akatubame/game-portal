## 今回の対象7ゲーム

| ゲーム | 主な変更 |
| --- | --- |
| 数独 | 既存の直接日英表示を旧DOM翻訳の対象外へ変更。クリア文・問題名・補助記録表示を維持 |
| スネーク | リンゴ・一時停止・ゲームオーバー、記録と操作ボタンを日英表示。入力欄とゲームキー操作の干渉を防止 |
| ブロック崩し | ブロック破壊・残機喪失・クリア・一時停止・記録を日英表示。入力欄とキー操作の干渉を防止 |
| ポン | 得失点・勝敗・難易度・一時停止・記録を日英表示。入力欄とキー操作の干渉を防止 |

進行中のメッセージには第10段階の `useLocalizedMessage` を再利用し、発生時の日英文と数値を保持する。言語切替で盤面・スコア・COMの手番を初期化しない。既存の保存キー・ランキングキーは維持する。

## 検証

`npm run test:portal-phase12` を追加した。390px幅の隔離ブラウザで英語本文と読み上げ属性の日本語残り、日英往復時の通知・スコア維持を確認する。数独・イラストロジックはクリアまで、スネークはリンゴ取得からゲームオーバーまで、リバーシはプレイヤーとCOMの1手ずつ操作する。ソリティアは山札操作と記録リセット、ブロック崩し・ポンは開始と停止・再開を確認する。アーケード3ゲームでは入力欄フォーカス時のキー干渉を検査する。

一括コマンド `npm run test:portal-regression` に第12段階を追加した。

検証結果: 第12段階の7ゲームテスト、全16群の一括回帰テスト、将棋・麻雀の内包とPWA生成を含む公開用ビルドがすべて成功。`git diff --check` もエラーなし。

実機スマートフォン、本番URL、全ゲーム全難易度の完走は今回の検証対象に含まない。
