# Game Shelf ゲーム品質改善・第16段階

実施日: 2026-10-06

## 途中保存・再開を5ゲームへ追加

Word Guess、ポーカー、ヨットダイス、神経衰弱、Simon Saysにブラウザ内の途中保存を追加した。新規開始で旧局面を破棄し、終了時には途中記録だけを消す。従来のベスト記録・ランキングキーは変更しない。

| ゲーム | 保存内容 | 再開時の注意点 |
| --- | --- | --- |
| Word Guess | 答え、判定済みの単語、入力中の文字 | 候補単語・判定結果の整合を確認する |
| ポーカー | 山札、手札、交換予定のカード | 52枚の重複・欠損がないことを確認する |
| ヨットダイス | サイコロ、ホールド、残りロール、スコア表 | 役・点数・ラウンド状態を検証する |
| 神経衰弱 | カード配置、成立ペア、手数、経過秒 | 2枚目の判定待ちで再読み込みした場合は1枚目を開いた状態に戻す |
| Simon Says | 現在の色順 | 再読み込み後に現ラウンドを最初から再提示し、入力途中の操作をリセットする |

各キーは `game-shelf-progress-*-v1`。不正な保存値は復元せず、読み込み時には削除しない。神経衰弱のような短い演出中も操作不能な盤面は保存しない。計時はページを閉じている時間を加算せず、再開後に進める。答え・カード順などはローカル保存値から閲覧できるため、対戦・賞金を伴う用途には使わない。

## 検証

`npm run test:portal-phase16` を追加。5ゲームで入力途中の再読み込み、盤面・履歴の復元、新規開始、終了後の途中記録削除、破損データの拒否を確認する。ヨットダイスは全13役、神経衰弱は全ペアを通して完走する。320px・390px幅で横方向のはみ出しがないことも検査する。全体の `npm run test:portal-regression` に組み込んだ。

検証結果: 第16段階の個別テスト、全20群の一括回帰テスト、将棋・麻雀の内包とPWA生成を含む公開用ビルドが成功。`git diff --check` もエラーなし。第13～16段階で途中再開に対応したゲームは計18作。

実機スマートフォン、別端末間の同期、残りのゲームの途中保存は未対応。この作業からのcommit・push・deployは未実施。
