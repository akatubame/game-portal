# Game Shelf ゲーム品質改善・第6段階

実施日: 2026-10-05

## 対応内容

三目ならべ・コネクトフォー・Nim・ブラックジャック・Word Guessの終了時記録を、累計戦績とは別の読み取り専用スナップショットとして保持する。

- 三目ならべ・コネクトフォー・Nim: 終了時の連勝数をランキング表示・登録に使用。
- ブラックジャック: 終了時の所持チップ数を使用。
- Word Guess: 今回の結果に添える連勝数を保持。
- 戦績リセットで累計値が初期化されても、今回の記録は変更しない。
- 新規ゲーム開始時は前のスナップショットを破棄。難易度変更による新規開始も同様。
- 保存キーや既存のランキング記録は変更・削除しない。

これは問題のあった5ゲームの終了記録分離であり、全ゲーム共通の結果型への全面移行ではない。非掲載ゲーム、カラーチェイン、内包将棋・麻雀のコードは変更しない。

## 検証

`npm run test:portal-phase6` を追加。隔離Edgeの390px画面で5ゲームを終了まで操作し、削除キャンセル・確定、日英往復切替、登録、再開を確認。実ユーザー記録は使わず、対象ローカルorigin以外の通信を遮断する。

5ゲームのテストは成功。削除後に登録したランキングの保存スコアが終了時の値と一致することも確認済み。

保存処理・数独のコアテスト、第2段階のブラウザ回帰テスト、内包ゲームを含む本番用ビルドも成功。実スマートフォン・全難易度の完走は対象外。
