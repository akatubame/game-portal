# Game Shelf ゲーム品質改善・第14段階

実施日: 2026-10-06

## 途中保存・再開を5ゲームへ拡大

ライツアウト、タワー・オブ・ハノイ、ペグ・ソリティア、Flood Fill、さめがめに、ブラウザ内の進行中データ保存を追加した。ページ再読み込み後も同じ盤面から続けられる。新規開始では旧局面を破棄し、クリア・手詰まり・失敗などの終了時には途中記録だけを消す。ベスト記録とランキングの保存キー・計算方法は変更しない。

| ゲーム | 保存内容 | 読み込み時の主な検証 |
| --- | --- | --- |
| ライツアウト | 難易度、点灯盤面、手数、経過秒 | 盤面サイズ・真偽値・未クリア状態 |
| タワー・オブ・ハノイ | 円盤数、3本の柱、手数、経過秒 | 円盤の重複・欠損なし、各柱の積み順、未完成状態 |
| ペグ・ソリティア | 7×7盤面、手数 | 盤外マスの位置、残数と手数の整合、合法手の有無 |
| Flood Fill | 難易度、色盤面、手数 | 色とサイズ、制限手数内、未クリア状態 |
| さめがめ | 難易度、色盤面、点数、直前消去数 | 色とサイズ、非負の点数、消せる塊の有無 |

各キーは `game-shelf-progress-*-v1`。壊れた盤面は復元せず、読み込み時に元データを削除しない。計時があるゲームは第13段階と同じく、ページを閉じている間はタイマーを止め、再開後から計時する。保存不能時は従来の `safeStorage` のタブ内一時保存と案内に従う。

## 検証

`npm run test:portal-phase14` を追加。5ゲームで一手進めた後の再読み込み、新規開始、クリア後の途中記録削除と結果登録欄の保持を確認する。ハノイは不正な円盤順序も拒否する。320px・390px幅でページ全体に横方向のはみ出しがないことを検査する。一括回帰 `npm run test:portal-regression` に組み込んだ。

検証結果: 第14段階の個別テスト、全18群の一括回帰テスト、将棋・麻雀の内包とPWA生成を含む公開用ビルドが成功。`git diff --check` もエラーなし。

実機スマートフォン、別端末間の同期、残りのゲームの途中保存は未対応。この作業からのcommit・push・deployは未実施。
