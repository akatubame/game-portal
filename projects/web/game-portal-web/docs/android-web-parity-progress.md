# Android版との機能統合：進捗と残作業

## 基準

- ローカル四枚麻雀Android：2.7.0（44）。
- ローカルランダム将棋Android：1.7（8）。
- Google Play配布版との一致は未確認。広告・課金・購入復元はWebへ移植しない。
- ルール・得点・保存・抽選に続き、履歴・復元・翻訳・更新安全性まで実装。ネイティブ固有機能と実機検証は下記の留意事項を参照。

## 実装済み

### 四枚麻雀

- 5枚目の同種牌による和了・待ちを排除。暗槓との物理枚数も検証。
- 暗槓の牌を役判定とドラ・裏ドラ・和了牌記録に含める。
- 嶺上牌取得時は通常山を1枚減らす。補充不能時は暗槓を拒否。嶺上と海底の重複を防止。
- ロン見送り後に後順位のCOMを確認。前順位は再確認しない。
- COM立直中のツモ切り、初級の立直・暗槓禁止、中級の確率判断を反映。
- 開始親をランダム化。終局時は最後の局・親を保持。
- ロン確認中の打牌、立直後の手出し、終局後の次局操作を拒否。
- 対局ID・局通番による戦績の区別。同結果の別対局を記録する。
- 旧保存から移行し、対局・戦績・集計済みキーを一つの保存単位へ統合。
- 保存失敗時もプレイは継続し警告を表示。旧保存キーは移行用に残す。
- 結果画面の復元、終局済み対局の再開防止、保存値の検証強化。
- 古い自動打牌タイマーは現在の状態と一致する場合だけ反映。

### ランダム将棋

- 打ち歩詰め、不正な成り指定・駒種指定・成駒打ちを拒否。
- COM要求を独立したモジュールへ分離。要求ID、取消、WASM初期化を含む時間上限を追加。
- 外部COMが失敗した場合は内蔵COMへ移行。それも失敗した場合は合法手で継続し、通信失敗を勝利にしない。
- 投了・待った・ホーム移動・新局面生成時にCOM要求を取消。成功したWASMエンジンは再利用。
- 思考途中の待ったでも棋譜の戻し幅を正しく計算。
- Androidの167局面を取り込み。駒総数、二歩、行き所のない駒、王手の整合、手番側有利・合法手ありを確認して抽選する。
- 無関係な戦型名の割当を廃止。系列→元棋譜→局面の順に抽選する。
- 手数だけの差と先後反転を同一局面と判定。未出題優先、既出最大10,000件、直近の系列・棋譜・構造を考慮。
- 既存局面を出題し尽くした場合のみ短い合法手派生を試す。失敗時も検証済み局面に戻す。

## 追加実装（残タスク対応）

- 将棋：途中対局の復元、対局履歴（最大50件）、難易度・勝敗フィルタ、棋譜表示、同局面再挑戦、担当先後を入れ替えた再挑戦。保存容量超過や保存失敗を通知。
- 将棋：COMの最低待ち時間を選択可能。中級600ms・上級2000msの外部エンジン思考時間を設定（最低待ち時間とは別）。古い応答の破棄と失敗時の代替処理を維持。
- 麻雀：役名の保存を安定IDへ移行し、旧保存値を読み替え。新規対局ログを構造化。COMの同シャンテン時の打牌優先順位を調整。
- 両ゲーム：DOMの事後書き換えを廃止し、描画時の翻訳へ統合。動的な結果・局名・棋譜・追加局面も翻訳。
- 入力：将棋の指し手・待ったの連打、麻雀の旧画面からの操作を防止。保存・COM・翻訳を独立モジュールへ整理。
- PWA：更新による自動再読込をやめ、利用者が更新ボタンを押すまで対局画面を維持。初回登録では更新通知を出さない。
- 開発・プレビュー環境でも内包将棋のWASMに必要な分離ヘッダーを設定。スマホ幅で将棋ボタンの視認性、麻雀の英語風牌表記を調整。

## 検証

- 四枚麻雀：既存・境界条件・保存移行・全3難易度×全4開始席からの終局テスト。
- 将棋：反則、古いCOM応答、取消、タイムアウト、局面パックと抽選のテスト。
- 各ゲームの型検査・本番ビルドと、ポータル内包ビルドを実施。
- 単体・回帰テスト：将棋23件、麻雀57件、計80件成功。
- Playwrightと隔離したEdgeで日英それぞれ390×844の操作を検証。将棋は指し手・COM応答・待った・再読込復元・投了・履歴・フィルタ・先後入替、麻雀は実際の打牌から局終了・結果翻訳・再読込復元・牌画像を確認。横はみ出し・ページ例外なし。
- ポータルの本番ビルドをローカル配信し、将棋WASMの実応答、牌画像、キャッシュ後のオフライン起動、初回PWA登録時の再読込抑止を確認。controllerchangeイベントを擬似発火し、通知のみで対局画面が再読込されず、明示更新で再読込することを確認。
- 再検証コマンド：各ゲームの npm test、将棋側の npm run test:browser と npm run test:delivery。後者はポータルのプレビュー（既定4175番）を起動して実施。
- Android自体の改変、Git commit/push、Cloudflareへのデプロイは行っていない。

## 残る確認・留意事項

1. Android・iPhoneの実機でタッチ操作、バックグラウンド復帰、インストール済みPWAを確認（今回のスマホ確認はデスクトップブラウザの画面幅検証）。
2. デプロイ後、旧版から新版への実際のService Worker更新と、Cloudflare本番のWASM・画像配信を確認。擬似イベント試験だけで全更新経路を保証するものではない。
3. 対局履歴・戦績は端末のブラウザ内保存であり、端末間同期ではない。ブラウザデータ削除で消える。

AndroidネイティブエンジンとWeb WASMは別実装であり、完全に同じ指し手・棋力になる保証はしない。思考時間、合法性、体感難易度を別途比較する。
