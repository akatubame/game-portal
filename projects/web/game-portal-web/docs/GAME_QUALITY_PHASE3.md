# Game Shelf ゲーム品質改善・第3段階

最終確認日: 2026-10-05

## 今回の対応

### カウントアップ計時と終了時間

対象: 神経衰弱、15パズル、ライツアウト、ハノイ、数独、マインスイーパー、迷路脱出、Hit&Blow。

- 通知回数による秒数加算をやめ、共通の useStopwatch で開始時刻から経過時間を計算する。
- 非表示タブなどでタイマー通知が遅れても、復帰時に経過分を反映する。
- クリア・失敗時は計時を停止し、その時点の値を表示・保存に使用する。
- 既存の最低1秒という記録仕様を持つゲームは、その仕様を維持する。
- リセットや新しい問題・難易度の開始で計時もリセットする。
- 既存の保存キーと記録は保持する。過去記録の補正や一括削除はしない。
- 1to50とソリティアは既に開始時刻ベースのため、今回は変更していない。

この統一は計時に関するものであり、すべてのゲームの終了結果を共通データ型へ移す作業とは別。

### 翻訳の直接表示

- 共通ランキングの見出し、入力欄、登録状態、空欄案内、削除確認をReactから直接日英表示する。
- ユーザーが入力した名前を翻訳対象から除外する。
- 保存済みの結果表示・補足文は既存の翻訳辞書を純粋な変換関数として利用する。保存済み文字列の全面的な構造化や逆翻訳は未対応。
- 神経衰弱はゲーム名、説明、進行・クリアメッセージ、難易度、カードの読み上げラベル、ベスト表示、操作ボタンを直接日英表示へ移行する。
- 上記領域に data-native-i18n を付け、従来のDOM翻訳処理による上書きを防ぐ。
- 全ゲームのDOM翻訳はまだ廃止していない。

### ランキングの削除確認

- 削除ボタンを一度押しただけでは削除しない。
- 削除対象が「このブラウザのこのランキング」であり、元に戻せないことを日英で表示する。
- キャンセルでは記録を保持し、削除確定時のみ対象ランキングを削除する。
- 各ゲーム固有のベスト削除・記録リセットへの確認追加は未対応。

## 検証

追加テスト: `npm run test:portal-phase3`

ローカル4180番サーバー、ワークスペース内の既存Playwright、Microsoft Edgeを使用。隔離プロファイルで対象origin以外の通信を遮断する。

- 対象8ゲームで31秒分の通知遅延を模擬し、時間表示を確認。
- 神経衰弱を最後まで解き、画面とランキングの時間一致・終了後の時間停止を確認。
- 神経衰弱のクリアメッセージと説明見出しを日本語→英語→日本語で切り替えて確認。
- 日本語のランキング名が英語モードでもそのまま保たれることを確認。
- 削除操作のキャンセルと確定を確認。
- 第1・第2段階のブラウザ回帰テストも実行済み。公開内蔵34ゲームの通常・保存拒否・不正データ条件での起動確認を含む。
- 数独・保存処理のコアテスト、カラーチェインの既存3種のロジックテストを実行済み。
- 2026-10-04に利用制限で中断した神経衰弱の最終翻訳検証を、2026-10-05に再実行して成功。

全ゲーム全難易度の完走、実スマートフォン、本番公開環境での確認は含まない。

## 残タスク

1. 残る各ゲームの直接日英表示への移行と、翻訳済み文字列ではなく構造化した結果データの保存。
2. 終了結果の共通データ化と、記録リセット後も直前の結果が変わらないようにする整理。
3. 各ゲーム固有の記録削除・リセットの確認。
4. ヒント利用時の記録分離、途中保存、迷路の最短時間と最短手数の独立記録。
5. 実機スマートフォンの追加QA、ゲーム完走テストの拡充。

commit・push・deployは実行しない。別開発中のカラーチェインと内包将棋・麻雀のゲームロジックは変更していない。
