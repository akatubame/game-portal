| ゲーム | 主な変更 |
| --- | --- |

6ゲームの動的メッセージには第10段階の `useLocalizedMessage` を再利用した。発生時の数値を日英文へ同時に格納し、言語切替で盤面や点数をリセットしない。保存キー・ランキングキー・ルールは維持した。

## 検証

`npm run test:portal-phase11` を追加し、390px幅の隔離ブラウザで12ゲームの開始・操作・日英往復・得点維持を確認する。Hit & Blowは1回で正解、さめがめは全消し、ハノイは3枚7手でクリア、Water Sortは注ぎとUndoを確認する。英語本文と読み上げ属性の日本語残りを検査するが、タイピングの日本語出題フレーズだけは対象外とする。

一括コマンド `npm run test:portal-regression` に第11段階を追加した。公開34ゲームの通常・保存拒否・不正データでの起動確認と、既存テスト群を含む。

最終検証: 全15テスト群の一括回帰に成功。内包将棋・麻雀を含む公開用ビルドにも成功し、PWAと検索用ページを生成した。差分の空白エラーを確認済み。

実機のスマートフォン、全ゲーム・全難易度の完走、本番URLは今回の検証対象に含まない。
