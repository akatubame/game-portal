# Game Shelf ゲーム品質改善・第4段階

実施日: 2026-10-05

## 補助利用による記録分離

- 数独はヒントの使用、イラストロジックはプレイ中の答え確認を契機に「補助あり」へ切り替える。
- 問題ごとに補助あり／なしのベスト記録・ランキングを分ける。答えを再び隠しても補助利用は取り消さない。
- 新しい問題・やり直しで補助なしから開始する。クリア後の答え確認では確定済みの区分を変えない。
- 行列ヒント、自動×、重複警告など通常ルールの補助表示は区分変更の対象外。
- 旧記録は補助の使用状況が不明なため、補助なし記録へ移さず「以前の記録」に保持する。以前のベストとランキングは折りたたみ表示で閲覧できる。
- ベストは既存保存マップの新キー、ランキングは新しい区分別キーを使う。既存データを自動削除しない。
- 新しい区分の案内はReactから直接日英表示し、DOM翻訳による上書きを除外する。

## ゲーム固有の記録リセット確認

対象28ゲーム: エイム練習、ブラックジャック、ブロック崩し、カラー判定、コネクトフォー、Flood Fill、ハノイ、Hit&Blow、迷路、計算、Nim、イラストロジック、1to50、ペグ・ソリティア、ポーカー、ポン、反射神経、リバーシ、さめがめ、Simon Says、スネーク、ソリティア、三目ならべ、タイピング、Water Sort、もぐらたたき、Word Guess、ヨットダイス。

- ベスト削除・戦績リセットに日英の確認ダイアログを追加。
- キャンセルではリセット処理を実行しない。
- 元に戻せないこと、ランキングは別管理で削除されないことを明示。
- 元々個別リセットボタンがないゲームへの新規ボタン追加はしない。非掲載ハングマンと別開発カラーチェインは変更対象外。
