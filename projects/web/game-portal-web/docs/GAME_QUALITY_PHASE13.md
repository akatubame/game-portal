# Game Shelf ゲーム品質改善・第13段階

実施日: 2026-10-06

## 途中保存・再開の先行適用

2048、15パズル、数独、イラストロジックの途中盤面を、このブラウザのローカル保存へ自動保存する。ブラウザ再読み込みやポータルから戻って開き直した際、進行中の1局を復元する。ゲーム内の新規開始・リセット・問題変更とクリア時には途中記録を破棄する。ベスト記録とランキングは従来のキーを維持し、途中記録と分離する。

| ゲーム | 途中保存する内容 |
| --- | --- |
| 2048 | 盤面、点数、実際に動かした回数。勝利・ゲームオーバー状態は盤面から再判定 |
| 15パズル | 盤面、手数、経過秒。ページを閉じている間は計時しない |
| 数独 | 問題ID、入力盤面、経過秒、ヒント利用、重複数字の表示設定。ページを閉じている間は計時しない |
| イラストロジック | 問題ID、入力盤面、手数、選択中の道具、解答表示・補助利用状態 |

途中保存のキーはそれぞれ `game-shelf-progress-*-v1` とし、形式の版と盤面・問題ID・数値範囲を確認してから読み込む。破損・旧形式のデータは誤復元せず、読み込み時点では削除しない。保存不能時は従来の `safeStorage` によるタブ内一時保存と案内に従う。ほかの端末との同期は行わない。

## 共通記録

ランキングの `RankingEntry` 型と保存データの検証を `safeStorage` に統一した。旧版の `display` 欄がない記録を引き続き読み込み、表示時に補う。非数値の点数や不正な表示欄はランキングとして表示しない。既存の保存キーと順位付けは変更しない。

## 検証

`npm run test:portal-phase13` は4ゲームのリロード後の盤面・記録・補助利用状態、リセット時の途中記録削除、壊れた2048途中データ、旧ランキング記録と不正スコアを確認する。一括回帰 `npm run test:portal-regression` に追加した。
